Moli – Recetario Digital Interactivo
Descripción
Moli es una aplicación móvil de recetario digital diseñada para facilitar la experiencia de cocinar mediante herramientas inteligentes como ajuste automático de porciones, asistente de voz, checklist interactivo y temporizadores integrados.

El objetivo principal es acompañar al usuario durante la preparación de alimentos, reduciendo la necesidad de tocar el dispositivo cuando tiene las manos ocupadas.

Problema que Resuelve
Muchas recetas digitales no están optimizadas para su uso práctico en la cocina. Esto genera problemas como:
	•	Tener que tocar constantemente el celular.
	•	Dificultad para ajustar cantidades según porciones.
	•	Perder el orden de los pasos.
	•	No contar con temporizadores integrados.
Moli resuelve estos inconvenientes mediante una experiencia interactiva y funcional.

Público Objetivo
Dirigido a:
	•	Personas que cocinan en casa.
	•	Estudiantes.
	•	Familias.
	•	Principiantes en cocina.
	•	Amantes de la gastronomía.

La aplicación está diseñada para que cualquier persona pueda utilizarla fácilmente.

Funcionalidades Principales
	•	 Gestión de recetas.
	•	 Ajuste automático de ingredientes por número de porciones.
	•	 Checklist interactivo de ingredientes y pasos.
	•	 Asistente de voz para navegación manos libres.
	•	 Lectura en voz alta de la receta.
	•	 Temporizadores integrados.
	•	 Creación y edición de recetas.

 Flujo Principal del Sistema
	1.	Usuario ingresa a la app.
	2.	Busca o selecciona una receta.
	3.	Visualiza detalles.
	4.	Puede modificar porciones.
	5.	Activa modo cocina.
	6.	Puede activar temporizador.
	7.	Finaliza receta.
